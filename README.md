# Novis Media — High-Converting UGC & AI Video Creative Agency

> **"Small spark, big reach."**  
> Premium, video-forward marketing platform engineered for modern DTC brands, internet-native companies, and content creators.

---

## ⚡ Overview
**Novis Media** is a performance creative agency specializing in:
- **Performance UGC Ads**: Raw, native creator hooks engineered to maximize retention and print ROAS.
- **AI-Generated Commercials**: Hollywood-grade synthetic motion and impossible visual metaphors without six-figure studio costs.
- **AI Avatars & Auto-Edited Reels**: Autonomous digital likeness and voice cloning for daily hands-off short-form distribution.
- **Social Media Management**: Growth architecture across TikTok, Instagram Reels, and YouTube Shorts.
- **High-Converting Web & Funnel Architecture**: Sub-second Next.js e-commerce funnels tailored to match paid ad traffic.

---

## 🎨 Visual Identity & Theme
- **Background**: Near-black with deep forest undertone (`#0A0C0A`)
- **Surfaces**: Tactical deep moss cards (`#131711`) with hairline borders (`#272E26`)
- **Primary Accent (Gold)**: Reserved strictly for conversion CTAs (`#C6A15B`)
- **Secondary Accent (Emerald)**: Category tags, metrics, and indicators (`#3E7A5C`)
- **Typography**: Geometric Grotesque (`Bricolage Grotesque`) + Ultra-clean Modern Sans (`Inter`)

---

## 🚀 Tech Stack
- **Framework**: [Next.js 16 (App Router + Turbopack)](https://nextjs.org/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **SEO & Schemas**: Semantic HTML5, dynamic XML sitemaps, JSON-LD (`Organization`, `VideoObject`, `FAQPage`, `BlogPosting`)
- **Video Engine**: Scroll-triggered `IntersectionObserver` autoplay with custom audio controls

---

## 🛠️ Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Local Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Production Build
```bash
npm run build
npm run start
```
